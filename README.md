# Simulation et Augmentation de Données pour la Gestion Optimisée des Charges Énergétiques

## 📋 Description
Projet P2M utilisant les GANs pour générer des données synthétiques de consommation énergétique et les VAEs pour la désagrégation énergétique.

## 🎯 Objectifs
- Générer des signaux de consommation réalistes avec GAN
- Désagréger la consommation globale avec VAE
- Améliorer la gestion énergétique domestique

## 🛠 Technologies
- Python, TensorFlow/Keras
- GAN (Generative Adversarial Network)
- VAE (Variational Autoencoder)
- Dataset REFIT

## 📊 Résultats
- MAE: 6.37
- Accuracy: 82.44%
- Precision: 83.34%
- Recall: 94.65%
- F1-Score: 88.63%
